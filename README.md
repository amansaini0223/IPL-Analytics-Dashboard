# 🏏 IPL Analytics Dashboard

An interactive IPL Analytics Dashboard built using **Python, Pandas, Plotly, and Streamlit**. This project analyzes IPL matches and ball-by-ball data from **2008 to 2020**, providing detailed insights into teams, batters, bowlers, venues, and all-time IPL records.

## 🚀 Features

### 📊 Dashboard Overview

* Total Matches
* Total Teams
* Total Runs
* Total Wickets

### 🏏 Team Analysis

* Team Performance Statistics
* Win Percentage
* Team Wins Comparison
* Head-to-Head Analysis

### 🏏 Batter Analysis

* Runs, Balls, Fours, Sixes
* Strike Rate
* Boundary Percentage
* Top Run Scorers
* Top Six Hitters
* Top Boundary Hitters
* Top Strike Rate Batters
* Orange Cap Leaderboard

### 🎯 Bowler Analysis

* Wickets, Economy, Runs Conceded
* Top Wicket Takers
* Top Economy Bowlers
* Top Dot Ball Bowlers
* Purple Cap Leaderboard

### 🏟️ Venue Analysis

* Venue-wise Match Statistics
* Most Successful Team at Venue
* Top IPL Venues

### 🏆 IPL Records

* Highest Run Scorer
* Highest Wicket Taker
* Most Sixes
* Most Fours

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Plotly
* Streamlit

## 📂 Dataset

* IPL Matches Dataset (2008–2020)
* IPL Ball-by-Ball Dataset (2008–2020)

## 🎯 Project Goal

The goal of this project is to transform raw IPL data into meaningful visual insights through interactive dashboards, helping users explore player performances, team records, venue statistics, and historical IPL trends.

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
